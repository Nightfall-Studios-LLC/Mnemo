# Security policy

Mnemo is pre-alpha and does not yet publish supported security-maintenance versions.

Do not disclose suspected vulnerabilities in a public issue. Use GitHub private vulnerability
reporting for this repository. If that feature is unavailable, contact the maintainer privately
and share only the minimum information needed to establish a secure channel.

Security-sensitive areas include OAuth client data, provider authentication tokens, arbitrary
file access, path traversal, backup integrity, restore integrity, archive extraction, and remote
storage integrations. Never include real credentials, tokens, private save data, or exploit data
in public reports or logs.

A useful report describes the affected revision, impact, reproduction conditions, and suggested
mitigation. Please allow maintainers time to investigate before public disclosure.
