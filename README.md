# Mnemo

Baseplate desktop application built with Tauri 2, React 19, TypeScript, and Vite.

## Prerequisites

- Node.js 24 or newer
- Rust stable with the MSVC toolchain
- The platform dependencies listed in the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/)

## Development

```powershell
npm install
npm run tauri dev
```

Build the frontend independently with `npm run build`, or create a desktop build with
`npm run tauri build`.
