# Roadmap

Roadmap entries are directional and not promises. Priorities may change as the architecture and
community mature.

## Phase 0 — Foundation

- Qt application shell
- Architecture
- Provider interface
- Save manifest/database design
- Game definition format

## Phase 1 — Local Saves

- Detect installed games
- Locate save directories
- Manual backup and restore
- Backup history
- Local provider
- Individual save/world selection

## Phase 2 — Remote Storage

- Provider API
- External drive provider
- NAS / SMB
- Google Drive
- MEGA

## Phase 3 — Synchronization

- Multiple computers
- Save comparison
- Conflict detection
- Automatic synchronization

## Future

- Community providers and game definitions
- Steam Deck / Linux
- Import/export
- Richer save metadata
