# Assets

Approved application artwork belongs here. No temporary image should be treated as Mnemo branding.

When a real icon is available, place it at `assets/icons/mnemo.svg`, add it to `resources.qrc` as
`:/icons/mnemo.svg`, and add an `.ico` variant when Windows executable resource metadata is
introduced. Product screenshots belong in `assets/screenshots/` only after real functionality is
available.
